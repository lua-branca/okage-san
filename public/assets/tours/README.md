# ツアーの写真置き場

回ごとにフォルダを作って入れてください。

```
tours/
├── 2026-02-11/     ← 開催日のフォルダ
│   ├── 01.jpg
│   ├── 02.jpg
│   └── ...
└── 2026-09-23/
```

## 決めごと

- フォルダ名は **開催日（YYYY-MM-DD）**。ツアーのファイル名と揃える
- ファイル名は **01.jpg / 02.jpg ...**（並べたい順）
- 横1600px程度・JPEG。スマホ写真はそのままだと重いので縮小してから
- 🔴 **参加者の顔が特定できる写真は載せません**（後ろ姿・引き・手元は可）

## サイトへの出し方

ツアーのファイル（`src/content/tours/YYYY-MM-DD-*.md`）の末尾に：

```yaml
report:
  photos:
    - src: /assets/tours/2026-02-11/01.jpg
      caption: 安房神社の参道（キャプションは省略可）
    - src: /assets/tours/2026-02-11/02.jpg
```

文章がなくても写真だけで成立します。
その場合、見出しは自動で「この日の写真」になります。
